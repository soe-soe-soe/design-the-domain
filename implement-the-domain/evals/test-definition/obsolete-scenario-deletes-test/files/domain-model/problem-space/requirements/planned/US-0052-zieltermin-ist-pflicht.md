# US-0052: Zieltermin ist Pflicht

Status: ready · Topic: Zieltermin · createdAt: 2026-10-26

Als Projektleiter möchte ich, dass jede Frist einen Zieltermin hat.

## Why

Eine Frist ohne Zieltermin kann nie überfällig werden und fällt deshalb nie auf.
