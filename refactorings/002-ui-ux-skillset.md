# Refactoring 002: UI/UX skillset

Status: open

The plugin has no skills for UI and UX yet. Problem, test and solution space cover rules,
scenarios and code structure; how a feature looks and how users move through it is defined
nowhere.

Comparison point: BMAD keeps a UX specification of its own next to the PRD, OpenSpec has none.

## To decide

- Which artefacts the skillset produces (UX spec, user journeys, screen states, design tokens).
- Where it sits in the workflow: after `requirement`, before `solution-definition`, or
  alongside both.
- How UI decisions reference stories and FR scenarios without mixing them into the problem
  space.
