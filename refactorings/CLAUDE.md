# Refactorings

Each file here is one planned refactoring of the plugin.

- **Numbering.** File names start with a three-digit number, counted up across all refactorings,
  the archived ones included: `004-<slug>.md` follows the highest number in this folder and in
  `archive/`. A number is never reused.
- **Archive.** Once a refactoring is implemented, move its file into `archive/` unchanged in name
  and set its status to implemented. Open refactorings stay in this folder.
